Capstone 66 — AI Data Storytelling Dashboard 

Project Overview
This project answers the question: **Can AI help turn data into a clear story?** 
Using a public dataset of over 27,000 Steam video games, I utilized AI to clean the data, generate analytical questions, and build an interactive dashboard to uncover what drives player engagement.
